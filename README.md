# SeniorBuddy
A correspondence buddy for seniors

A system that uses LLMs (Large Language Models), Speachrecognition and Text to Speech provides virtual buddies to elderly people.
It shall provide a locally hosted virtual friend to talk to. A friend that listens and responds carefully and with empathy.
The basic system shall be easy to use with no or almost no classical screen and mouse or touch interface. It shall listen and respond.
It might present images on a screen or open a video call, but the screen shall not be the primary interface.

The system shall be extensible via add-ons and Plugins. So additional functionality can be added by the community later.
The first and primary task is to listen and talk. Not to order a pizza or to organize a date with the doctor. These things might come later.

The system shall provide several virtual friends with various personalities. 
There might be the fast responding but a little bit naive best friend (a smaller LLM) and a more sophisticated and intelligent but slower professor (another larger LLM).
The key is that all the data is kept locally on the local machine. A priori NO websolution. 
The users might give their permission to some web interfaces via add-ons, but the thing shall be and stay locally. All user data shall stay absolutely confidential, encrypted by default.
